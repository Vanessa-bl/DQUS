Un marketplace inmobiliario preparándose para su Serie B tenía una superficie de admin expuesta, una API de partners sin rate limits y un modelo de sesión que filtraba tenancy bajo ciertas condiciones de concurrencia. El review de seguridad de los inversores era en ocho semanas.

En seis semanas, modelamos amenazas sobre las tres superficies, parchamos la filtración de tenancy, sumamos rate limits y firmas autenticadas a la API de partners, endurecimos la superficie de admin contra el OWASP top-10 y corrimos un ejercicio red-team contra el ambiente de producción con un scope firmado.

El red team bloqueó cada intento del top-10, el reporte de diligencia volvió con cero hallazgos críticos y la ronda cerró en fecha. El approach de hardening es ahora el baseline para cada nueva integración de partners.
