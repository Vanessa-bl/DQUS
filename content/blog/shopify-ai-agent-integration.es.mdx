Una marca direct-to-consumer en Shopify quería un agente de IA que contestara a compradores en WhatsApp, recuperara carritos abandonados y hiciera lookup de status de pedidos. Lo deployamos en cuatro semanas. El path es el mismo para la mayoría de las tiendas Shopify.

## ¿Qué pasa en cada semana?

| Semana | Scope | Entregable |
| --- | --- | --- |
| 1 | Sync de catálogo, auth, búsqueda de producto | El agente devuelve ítems en stock con precios reales |
| 2 | Lookup de pedidos, status, tracking | El agente responde "dónde está mi pedido" desde datos en vivo |
| 3 | Recuperación de carrito, outreach a abandonados | El agente contacta con los ítems y la promo exactos |
| 4 | Evals, topes de costo, path de escalación | El agente está listo para producción con guardrails |

## ¿Dónde se traban los equipos?

- **Cache de stock.** El equipo cachea el catálogo semanalmente para ahorrar llamadas. El agente vende un ítem sin stock. Fix: lookup de stock en tiempo real con cache de TTL corto.
- **Inferencia de promociones.** El agente lee un banner de marketing y empieza a ofrecer un descuento que nadie aprobó. Fix: las promos solo vienen de la API de precios.
- **Path de escalación.** Un cliente tipea "cancelar mi pedido" y el agente sigue respondiendo como si fuera búsqueda. Fix: intents de escalación explícitos, entrenados antes del go-live.

## Preguntas frecuentes

### ¿Necesito el plan Shopify Plus?

No. La Storefront API y la Admin API de los planes estándar de Shopify alcanzan para la mayoría de los agentes. Plus ayuda si necesitás customizar el checkout.

### ¿Y las features de IA del propio Shopify?

Son útiles para búsqueda de producto dentro del admin. Para un agente orientado al comprador que transaccione, lo construís arriba de las APIs.
